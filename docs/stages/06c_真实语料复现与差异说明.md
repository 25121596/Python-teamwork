## 没有掩盖的复现差异

本轮不能称为原 Windows 模型的逐字节复现：训练词表与 IDF 指纹不同。NB alpha=1 的验证误报从 135 变为 136，alpha=0.5 从 135 变为 134；其他五组的指标不变。获选 NB alpha=0.1 与 LR C=2 的验证成绩、两族最优参数及最终候选完全相同。LR 验证 TN=3201、FP=11、FN=47、TP=1840。

检查本机 scikit-learn `_limit_features` 源码发现，max_features 截断按词频 argsort，未明确使用词汇序的平局规则。跨平台对截止处同频词的处理是合理假设，但没有原 Windows 私有词表，不能证明具体差异词或唯一原因。本次没有为了重现旧指标改参数或反复挑选词表；明确版本化本轮已核验结果。旧结果仍保留在 Git 历史 `cd8e106`。
