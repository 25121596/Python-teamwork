## 构建与核验

采用独立文档环境的 `python-docx==1.2.0`，不改变科学实验依赖锁：

```bash
python scripts/build_report.py
```

模板 A4 与页边距保持不变；正文宋体 12 磅、标题黑体，模板空白段落适当压缩。制作机用已安装中文字体回退渲染；小组 Word 字体不同可能改变分页，应在提交电脑复核。生成器会覆盖同名文件，手工编辑前另存副本。

通过 LibreOffice 渲染，逐页查看全部 11 页，修正尾页溢出、手动分页空页与封面填写线。图片不截断、表格不跨页拆行，目录页码为 3/3/4/5/6/8/10/10/11，与正文逐项一致。图表、验证与测试数值来自 JSON；代码附录的执行顺序对应最终评估入口。记录见 `artifacts/audit/report_delivery_validation.json`。

旧的 `项目报告草稿.docx/.md` 从当前树移除，历史提交仍可恢复，避免误交旧验证版。
