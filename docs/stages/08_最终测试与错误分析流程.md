## 执行与产物

```bash
python scripts/compare_cleaning.py
python scripts/check_ablation.py
python scripts/evaluate_final.py
python scripts/check_final_results.py
```

前两条必须先成功；缺失锁或验收时后两条停止。独立检查重算指标、核对行序与冻结来源，并重载相同模型验证预测，不训练模型。

| 产物（真实运行后才生成） | 范围与用途 |
|---|---|
| `artifacts/metrics/stage08_test.csv`、`final_evaluation.json` | 多数类、NB、LR 最终测试指标与完整混淆计数 |
| `artifacts/figures/stage08_*_confusion.png` | NB、LR 混淆矩阵；轴明确标示真实与预测标签 |
| `artifacts/metrics/error_analysis.json` | 错分质量标记聚合、预设公开词表内 LR 正负系数 |
| `artifacts/figures/stage08_lr_public_terms.png` | 分类关联词，不能当作全词表排名、频率或因果解释 |
| `artifacts/audit/final_evaluation_validation.json` | 独立最终验收 |
| `artifacts/processed/stage08/` | 测试访问标记、逐封预测与待审真实错分文本；全部被 Git 忽略 |

NB、LR 分别按置信分数绝对值选最多 15 个 FP 和 15 个 FN，不足时全部选取，以 ID 打破同分。这是确定性的人工审核候选，不代表错分总体的随机样本。`error_review.json` 初始全部 `reviewed=false`；组员须阅读原文、填写原因和安全改写，不能用自动 HTML/短文本标记直接断言错因。公开报告只用人工复核后的脱敏概述，不上传真实邮件或该私有文件。
