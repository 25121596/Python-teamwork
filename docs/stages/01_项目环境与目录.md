**执行方法**

在仓库根目录使用 Python 3.12 创建 `.venv`，通过该环境执行：

```powershell
.\.venv\Scripts\python.exe -m pip install --disable-pip-version-check --no-input -r requirements.in
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts\check_environment.py
```

本机先安装直接依赖并完成验证，再通过 `pip freeze` 生成精确版本清单。其他组员按 README 使用 `requirements.txt` 安装经过验证的版本。

环境脚本默认优先读取被忽略的 `config.local.json`，否则使用示例配置；也支持 `TREC06C_ROOT` 覆盖数据位置。数据相对路径以配置文件目录为准，输出相对路径以项目根目录为准。原始数据必须位于仓库之外，索引中邮件路径以 `full/index` 所在目录解析。
