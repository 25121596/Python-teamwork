# 协作与阶段提交约定

日期：2026 年 10 月 13 日。

目标：落实每完成一块工作就 Git 提交并上传 Markdown 的要求，使代码、分析过程、验收证据与报告材料可以逐阶段追踪。

本阶段建立三份文件：

- `AGENTS.md`：规定阶段检查、Markdown 记录、commit、push 和远程核验流程。
- `进度记录.md`：列出已完成与待完成阶段。
- 本文件：作为第一份阶段记录，提供后续记录格式。

本阶段为文档变更，检查内容包括 Markdown 文件是否完整、相对链接目标是否存在以及 `git diff --check`。未执行邮件清洗或模型训练。

后续阶段按以下内容编写记录：

| 记录项 | 应写内容 |
|---|---|
| 目标与状态 | 本阶段解决什么问题，是否达到验收条件 |
| 主要改动 | 新增或修改的代码、配置与文档 |
| 执行方法 | 工作目录、环境、运行命令、必要参数和前置条件 |
| 验证结果 | 实际检查、样本量、结果、异常；未运行的内容明确说明 |
| 产物位置 | 代码、聚合指标、图表或文档的位置；不公开原始邮件正文 |
| 问题与局限 | 发现的问题、处理方式和仍未解决的事项 |
| 下一步 | 后续任务与依赖 |

最初约定的环境准备和索引审计已分别完成，详见后续阶段记录。

2026 年 10 月 13 日补充 [执行清单](../../执行清单.md)，沿用项目计划的十步编号，标明当前完成状态、第三步任务、每阶段提交流程和课程截止时间。README 与进度记录增加导航，AGENTS 要求后续每阶段同步更新执行清单。本次为文档更新，没有启动第三步解析清洗。检查范围为 Markdown 链接、步骤与状态一致性以及 `git diff --check`。
