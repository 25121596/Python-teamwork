## 指导文档的执行要点

1. 以 `full/index` 为唯一入口，原始邮件和正文缓存保持本地。
2. 保留冻结划分和开发样本约束，训练侧拟合词表，验证集选型，最终测试只在方案锁定后执行。
3. 每块工作附阶段 Markdown，同时更新执行清单和进度记录，检查后提交并推送。
4. 老师模板、成员信息、真实个人贡献、五分钟录制和课程提交状态不能推测或虚构。
