**邮件清洗人工示例**

以下全部为人工构造的演示输入，不是实际语料摘录。真实邮件原文、解码后文本和清洗缓存只保存在本地；本文件展示处理机制，不代表对语料整体正确率的证明。

**HTML 与联系字段归一化**

人工 HTML，含 script/style、实体、邮箱、电话号码和网址。

清洗主题与正文：

```text
示例通知
会议&资料
邮箱 emailtoken ,电话 phonetoken ,网址 urltoken
```

状态：`ok`；所选正文含 HTML：`True`；MIME 任意部件含 HTML：`True`。

**GB2312 与编码主题**

主题使用 RFC2047 编码词，正文使用 GB2312。

清洗主题与正文：

```text
会议通知
请在明天上午查看会议资料。
```

状态：`ok`；所选正文含 HTML：`False`；MIME 任意部件含 HTML：`False`。

**错误 base64 声明**

人工正文已解码为中文字节，但头字段仍声明 base64。

清洗主题与正文：

```text
正文已经是可读中文,错误声明不应导致二次解码损坏。
```

状态：`recovered`；所选正文含 HTML：`False`；MIME 任意部件含 HTML：`False`。

记录的恢复动作：`mislabeled_base64_text_fallback`。

**缺失边界与装饰线**

人工 multipart 缺少实际声明边界，正文有装饰破折号。

清洗主题与正文：

```text
正常文本正文
----------------------
这只是装饰分隔线。
```

状态：`recovered`；所选正文含 HTML：`False`；MIME 任意部件含 HTML：`False`。

记录的恢复动作：`broken_multipart_text_fallback`。

**Alternative 选择**

同一正文提供纯文本和 HTML 版本，只保留有效纯文本。

清洗主题与正文：

```text
plain representation
```

状态：`ok`；所选正文含 HTML：`False`；MIME 任意部件含 HTML：`True`。

字符回退、替换符和 private-use 字符属于质量信号，不足以证明或排除语义乱码。短主题允许少量替换符以避免丢弃大部分仍可读的内容；普通正文使用更严格的拒绝阈值。
