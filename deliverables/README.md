## 正式视频制作

当前没有正式视频。真实实验和材料已完成；先确认错分观察，加入成员与实际分工，再彩排、录制。

1. 用小组电脑打开 PPT，逐页核对字体、数字、表格和备注。录制前关闭会弹出通知的程序，并确认画面不含原始邮件或个人信息。
2. 按讲稿彩排计时；每页时段合计为 5 分钟，是目标安排，不是已经录制出的真实时长。按实际语速删减重复表达，留出自然换页时间。
3. 在 Windows PowerPoint 的“录制”或“幻灯片放映”中的录制入口，用麦克风录入讲解与换页计时。界面名称随版本不同，详细操作见 [Microsoft：录制演示文稿](https://support.microsoft.com/zh-cn/powerpoint/record-your-presentation)。
4. 预览各页声音后，通过“文件 → 导出 → 创建视频”使用录制的计时与旁白，输出 MP4；建议 1080p。参见 [Microsoft：将演示文稿转换为视频](https://support.microsoft.com/zh-cn/powerpoint/turn-your-presentation-into-a-video)。
5. 完整播放导出文件，确认声音、画面、总时长及数字一致。不要只把无旁白的幻灯片导出成视频就标记完成。
6. 确认实际组号和组长姓名后，将正式 PPT、MP4 命名为课程要求的 `组号_6_组长姓名.pptx`、`组号_6_组长姓名.mp4`。这些是命名格式，不能把占位字原样提交。
